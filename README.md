# The Alchemist's Lock

A touch-friendly D&D rotating pipe puzzle with a built-in DM puzzle editor and player mode.

## Features

- 4×4 and 5×5 puzzle grids
- 2 or 3 colored liquids
- Straight, corner, T, cross, dead-end, and wall tiles
- Lockable tiles
- DM-defined sources and targets
- Puzzle validation and scrambling
- Player mode with animated valve testing
- Browser save/load
- JSON export/import
- iPad-friendly static site

## Netlify

This repository is a static site. Connect Netlify to the `main` branch and use the repository root as the publish directory. No build command is required.
